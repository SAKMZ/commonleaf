A commonplace book is where you keep the things worth keeping: a sentence from a
book, an argument you want to remember, a problem you have not solved yet.

Everything here is a Markdown file. This one lives at `content/welcome.md`. You
could delete this application tomorrow and still have every word, in a format
that will open in any editor for as long as text files exist.

## How it fits together

Notes link to each other with double brackets: [[Stoicism]] is a note about the
philosophy, and [[Atomic Habits]] holds reading notes on the book. A link to a
note that does not exist yet — like [[Marginalia]] — is drawn differently, and
following it creates the note.

Tags nest with slashes, so #books/philosophy sits beneath `books` and both are
browsable.

> [!note] Nothing is hidden
> Tags, links and titles are all read from the files themselves. There is no
> index to rebuild and no database to migrate.
